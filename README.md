# DeutschSchatzkiste

Ein deutschsprachiges Spieleportal für drei interaktive B2-Lernspiele: Pecha Kucha, Bowling-Allee und Wissensturm.

## Lokal starten

Unter Windows `START_SITE.bat` doppelt anklicken. Der lokale Server öffnet `http://localhost:8003/`.

Das Portal speichert Design- und Toneinstellungen ausschließlich lokal im Browser. Hintergrundmusik beginnt nach der ersten Interaktion, da Browser automatischen Ton vor einer Nutzeraktion blockieren.
